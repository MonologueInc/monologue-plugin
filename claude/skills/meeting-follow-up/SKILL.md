# Meeting follow-up

1. Find the requested meeting by title, participant, subject, or date. If ambiguous, show the likely matches before choosing.
2. Retrieve the selected note. Request its transcript when ownership, wording, or deadlines require more detail.
3. Separate explicit decisions, action items, open questions, and contextual observations.
4. Assign an owner or due date only when the note states one. Otherwise label it `Unassigned` or `No date stated`.
5. Draft the requested follow-up and cite the source as: note title — recording date — `note_id`.

The integration cannot send messages or modify notes. Present drafts for the user to review.
