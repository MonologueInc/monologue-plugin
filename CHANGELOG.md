# Changelog

## 1.0.0 — 2026-11-18

- Add portable Agent Plugins manifests (`plugin.json`, `mcp.json`).
- Add Codex, Claude Code, Cursor, Grok, and Gemini CLI adapters, published by Monologue Inc. from `MonologueInc/monologue-plugin`.
- Add the Monologue MCP integration over OAuth: list, search, and read notes with `notes:read`, read shared and public notes, and, with the `notes:write` permission, turn a note's public share link on or off.
- Add meeting preparation, meeting follow-up, weekly review, and general context skills.
- Add OpenAI review test cases, publication notes, a support URL, and a composer icon to the Codex manifest.
- Add marketplace submission packets and automated validation.
