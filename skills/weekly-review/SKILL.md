# Weekly review

1. Determine the review window. If the user says “this week,” use their local calendar week and state the dates.
2. Search notes using `created_after` and `created_before`, following pagination when needed.
3. Retrieve the relevant notes, using transcripts sparingly.
4. Organize the review into: themes, decisions, commitments, unresolved items, and suggested next steps.
5. Cite note-derived claims as: note title — recording date — `note_id`.

Do not imply that suggested next steps were commitments. Keep private details out of the review unless they materially answer the request.
